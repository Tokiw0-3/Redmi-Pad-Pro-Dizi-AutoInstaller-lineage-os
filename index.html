If LineageOS 23.0 is already installed and you want to update to 23.2 (2026.05.24), do not run flash.bat — it wipes your data.

3. Unlock Bootloader

Xiaomi requires a waiting period (usually 7 days / 168 hours) after binding your account. You cannot skip this.

3.1 Enable Developer Options

  1. Go to Settings → About tablet → Detailed info & specs
  2. Tap MIUI / HyperOS version 7 times until you see "You are now a developer"

3.2 Enable OEM Unlock & Bind Mi Account

  1. Go to Settings → Additional settings → Developer options (if no Developer options, see 3.1)
  2. Enable OEM unlocking
  3. Enable USB debugging
  4. Tap Mi Unlock status → Add account and device
  5. You should see "Added successfully" — this starts the 168-hour timer
ⓘ Critical
  • Do NOT sign out of your Mi Account or reset the device during the waiting period — the timer will reset
  • Do NOT tap "Add account and device" again — repeating it resets the timer too

3.3 Get unlock authorization via Mi Community app

  1. Install the Xiaomi Community app on your tablet (download from APKMirror or Xiaomi's site)
  2. Open the app and sign in with your Mi Account
  3. Go to Me → Unlock bootloader (may be under "Permissions" or "Services")
  4. Follow the on-screen prompts to apply for unlock authorization — approval can be instant or take time
  5. Once approved, you will receive confirmation in the app
ⓘ After approval

The 168-hour binding timer still applies from when you added your account in Developer options (step 3.2). Check Settings → Additional settings → Developer options → Mi Unlock status to see remaining time.

3.4 Unlock with Mi Unlock Tool

  1. Open the Mi_Unlock_Tool folder (included in this package)
  2. Run miflash_unlock.exe and sign in with the same Mi Account used on your tablet
  3. Power off your tablet, then boot into fastboot mode: hold Volume Down + Power until you see the fastboot logo
  4. Connect the tablet to your PC with a USB cable
  5. In the Mi Unlock Tool, click Unlock → Unlock anyway
  6. Wait for the process to finish — the tablet will reboot automatically
Note: If you see "Please unlock 168 hours later" or a similar timer, you must wait. After the waiting period, repeat from step 3.4 (power off → fastboot → unlock).

4. Flash LineageOS GSI

The .img file is already extracted in this folder. If missing, extract LineageOS-23.0-20260109-GAPPS-EXT4-GSI.7z using 7-Zip.

ⓘ Using a different GSI version (e.g. LineageOS 23.2 instead of 23.0)?

flash.bat expects the exact filename LineageOS-23.0-20260109-GAPPS-EXT4-GSI.img (hardcoded). To use any other GSI version with the script:

  1. Extract your .7z → you get a file like LineageOS-23.2-20260524-GAPPS-EXT4-GSI.img
  2. Rename it to LineageOS-23.0-20260109-GAPPS-EXT4-GSI.img
  3. Run flash.bat — it will find the image and flash it

Renaming only changes the label, not the contents. The image itself is untouched.

ⓘ Different HyperOS version — renaming your own vbmeta for Option B (manual)?

The flash.bat script uses the pre-patched vbmeta.img in this folder. It cannot be changed without editing the script. But if you use Option B (manual), you can substitute your own vbmeta:

  1. Extract vbmeta.img and vbmeta_system.img from your stock ROM (see requirements section above)
  2. Rename your clean/stock vbmeta.img → patched_vbmeta.img so it's clear this is your version's file
  3. Place both patched_vbmeta.img and vbmeta_system.img (from your ROM) into this folder
  4. In Option B1, use the renamed file: fastboot --disable-verity --disable-verification flash vbmeta patched_vbmeta.img

Naming it patched_vbmeta.img keeps the original pre-patched vbmeta.img intact in case you need it later.

A Automated — flash.bat

Option A

Run the automated flasher

  1. Boot tablet into fastboot mode (Volume Down + Power) and connect to PC
  2. Double-click flash.bat or run from CMD as administrator
  3. The script will handle every step: vbmeta → fastbootd → flash GSI → wipe → reboot
  4. First boot takes 5–15 minutes

Root after Option A

Root is optional — only needed if your HyperOS version differs from dizi_eea_global_images_OS3.0.2.0.WNSEUXM_20260421.0000.00_16.0_eea_7e549d23d8.tgz or the pre-patched boot doesn't work. Magisk is broken on dizi; use KernelSU.

  1. After booting LineageOS, install KernelSU_v3.2.4.apk (included in this folder)
  2. Copy your stock boot.img to the device
  3. Open KernelSU → Install → select boot.img → patch it
  4. Copy the generated patched_boot.img back to your PC
  5. Reboot to fastboot and run:
fastboot flash boot patched_boot.img
fastboot reboot

Advanced: use the included ksud-android CLI via ADB instead — see Option B root section.

B Manual — step by step

Option B

Flash manually via fastboot commands

B1 — Disable AVB verification

Boot into fastboot mode (Volume Down + Power). Connect to PC. Run:

fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img
fastboot --disable-verity --disable-verification flash vbmeta_system vbmeta_system.img

Both vbmeta.img and vbmeta_system.img are provided in this folder. If you extracted your own, rename your clean vbmeta.img → patched_vbmeta.img and use: fastboot --disable-verity --disable-verification flash vbmeta patched_vbmeta.img

B2 — Reboot to fastbootd

fastboot reboot fastboot

Screen changes from orange text to blue text (fastbootd).

B3 — Flash GSI

fastboot flash system LineageOS-23.0-20260109-GAPPS-EXT4-GSI.img

If your GSI has a different filename, replace it in the command, or rename your .img to match.

ⓘ Not enough space? Delete product logical partitions first: 
fastboot delete-logical-partition product_a
fastboot delete-logical-partition product_b
Then retry the flash.

B4 — Wipe & reboot

fastboot -w
fastboot reboot

First boot takes 5–15 minutes. Be patient.

  1. After booting LineageOS, install KernelSU_v3.2.4.apk (included in this folder)
  2. Copy your stock boot.img to the device
  3. Open KernelSU → Install → select boot.img → patch it
  4. Copy the generated patched_boot.img back to your PC
  5. Reboot to fastboot and flash:
fastboot flash boot patched_boot.img

Alternative — patch via ADB with ksud

Use the included ksud-android CLI for on-device patching:

adb push ksud-android /data/local/tmp/ksud
adb push boot.img /data/local/tmp/boot.img
adb shell chmod +x /data/local/tmp/ksud
adb shell /data/local/tmp/ksud boot-patch -b /data/local/tmp/boot.img
adb pull /data/local/tmp/patched_boot.img
fastboot flash boot patched_boot.img
fastboot reboot

6. Troubleshooting

BootloopYou likely skipped or mis-ran the vbmeta flash. Go back to step 4.2 and make sure both vbmeta images are flashed with --disable-verity --disable-verification. Re-run flash.bat or flash.ps1 entirely.
Not enough spaceDelete logical partitions (step 4.4 note) or ensure you extracted the EXT4 GSI (~3.2 GB) — it needs enough free super partition space
Stuck at logoForce reboot by holding Power + Volume Up for 10+ seconds. If it persists, reflash from step 4.2
Can't boot at allRe-flash the stock HyperOS fastboot ROM using Mi Flash Tool with "clean all" (not "lock") to recover
Fastboot not detecting deviceInstall Xiaomi USB drivers or use the driver installer included in the Mi Unlock Tool folder (MiUsbDriver.exe)
Camera / stylus / sensors not workingGSIs are generic — some device-specific hardware may not work perfectly. Check XDA forums for workarounds
Magisk bootloopUse KernelSU instead (see section 5). Magisk is broken on dizi.
